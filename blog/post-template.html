How I Built an Operations Dashboard That Cut Reporting Time by 60%

A deep-dive into the metrics design, SQL architecture, and PowerBI layout that made it work.

The Problem

Our team was spending 3 hours every Monday manually pulling warranty and RMA data from three different systems, formatting it in Excel, and emailing a PDF. The data was always a week stale.

The Solution

I built a unified SQL view that joined the three source tables, scheduled a Python script to refresh it nightly, and connected PowerBI directly to the view.

SELECT
  w.ticket_id,
  w.created_date,
  r.status AS rma_status,
  c.region
FROM warranty_tickets w
LEFT JOIN rma_records r ON w.ticket_id = r.ticket_id
LEFT JOIN customers c ON w.customer_id = c.id
WHERE w.created_date >= DATEADD(day, -90, GETDATE())
The result: Monday reporting went from 3 hours to 10 minutes, with live data.
