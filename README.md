# Shikhar Goswami — Portfolio

**Live site: https://shikhargoswami.github.io/my-portfolio/**

Product Manager portfolio: experience, impact, and the 0→1 products I've built.

Plain HTML, CSS and JavaScript, with no build step. Pushing to `main` deploys to GitHub Pages
through [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
